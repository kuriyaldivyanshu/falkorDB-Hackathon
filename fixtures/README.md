# Authored demonstration data

Fixtures are optional public examples for checking whether project memory helps a later native coding-agent session. They are not production state, migration inputs, execution sandboxes or memory-service startup dependencies.

The retained [inventory exporter](inventory-export-v1/README.md) supports the UTC-failure, changed-requirement and compatible-procedure demonstration. Its expected outputs describe the task; actual checks must produce their own observed evidence.

The [human memory walkthrough](../docs/memory-demo.md) copies the seed to a
disposable directory and captures freshly executed output outside Git. It
requires neither a native session nor an execution harness.

Keep future fixtures small and synthetic. Store no native credentials, private conversations, prefilled successful agent outcomes or machine-specific paths here. Package only explicitly selected demo assets.
